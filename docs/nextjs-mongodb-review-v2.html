Problem: every edit rewrites a whole collection blob, so a rev lock and a client 3-way merge exist only to survive it.

Solution: nine collections behind one repo module per collection. Existing ids become _id.

  • Delete KvMerge, rev, unsynced queue
  • Interface shrinks to per-record calls
  • Locality: all db access in repo
  • Deep links keep working
ADR: kv_store stays untouched until M7.5. export-to-kv.ts is the rollback adapter.

Solution: one change stream per process feeds SSE, and an idle client refreshes only its current route.
