Problem: the cache acts local-first but syncs whole-key blobs, and an offline boot can never write back.

Solution: a full SQLite DB per device; the repo module reads and writes locally and sync moves rows.

  • Zero-latency reads and writes
  • Offline writes finally sync
  • Delete KvMerge, rev, unsynced queue
ADR (Phase 0 spike, blocking): native self-hosted Turso bidirectional sync vs. own push/pull protocol on the same schema.

Problem: conflicts resolve through five round-trip steps over whole blobs.

Solution: one deterministic HLC compare per row; hot status fields get their own clock.

  • Deep: one rule, every table
  • Board moves survive concurrent edits
  • Property test: order-independent convergence
ADR: row-level LWW default; column-level only for status. Concurrent edits to other fields: later HLC wins, both logged in activity_log.

Solution: UUIDv7 identity locally; the gate mints the code on first push and it syncs back.

  • No offline collisions
